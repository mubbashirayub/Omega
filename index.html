What is HTML?

HTML (HyperText Markup Language) is the standard language used to create web pages. It defines the structure of a webpage using different tags.

Basic HTML Structure

Every HTML document starts with a <!DOCTYPE html> declaration, followed by the <html> tag that wraps the entire page.

Common HTML Tags

  • <h1> to <h6> — Headings of different sizes [^3^]
  • <p> — Paragraphs of text [^3^]
  • <a> — Links to other pages [^3^]
  • <img> — Images with src and alt attributes [^3^]
